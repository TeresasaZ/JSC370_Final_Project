# JSC370 Final Project – What are the key factors that influence traffic volume in Toronto?

## Project Description

This project investigates the key factors influencing traffic volume in Toronto from 2018 to 2022. It expands the scope to include additional variables such as time of day, weekday/weekend patterns, and the COVID-19 pandemic period. The project uses both statistical models (GAMs) and machine learning approaches (Tree, Bagging, Random Forest, Boosting, XGBoost).
